# MIGRACIÓN A GITHUB

## Repositorio

No crear un repositorio nuevo.

Mantener:

`GEOAVENTURAS-CR`

GitHub Pages puede seguir utilizando la misma configuración y la misma URL.

## Antes de subir esta v1.0

Eliminar los archivos obsoletos de los prototipos anteriores:

- `ar-limon.html`
- `marcador-prueba.html`
- `juego.js`
- `estilos.css`
- carpeta `datos/`
- archivos de mapas antiguos que no existan en esta nueva carpeta
- archivos `MANIFIESTO.json` de versiones v0.x

No eliminar el repositorio.
No modificar nuevamente `Settings → Pages`.

## Subir

Subir todo el contenido de esta carpeta a la raíz del repositorio:

```text
GEOAVENTURAS-CR/
├── index.html
├── ar-prototipo.html
├── README.md
├── MIGRACION_GITHUB.md
├── MANUAL_VISUAL_APLICADO.md
├── PENDIENTES.md
├── .nojekyll
├── assets/
├── css/
├── data/
└── js/
```

## Commit sugerido

`GeoAventuras CR v1.0 base de desarrollo`

## Después

1. Esperar que GitHub Pages quede en verde.
2. Abrir el sitio.
3. Forzar recarga con `Ctrl + F5` si aparece la versión anterior.
4. Probar:
   - nombre;
   - instrucciones;
   - San José;
   - cinco preguntas temporales;
   - aprobación/reintento;
   - cámara;
   - captura provisional;
   - desbloqueo de Puntarenas;
   - pasaporte.
