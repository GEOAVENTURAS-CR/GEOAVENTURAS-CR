# CAMBIOS IMPLEMENTADOS EN V1.1

## 1. Instrucciones
Se cambió:
- `ENCUENTRA EL TESORO`
por:
- `ENCUENTRA LA INSIGNIA`

## 2. Pantalla de provincia
Se dejó explícitamente reservado el espacio para la imagen final de cada provincia y se agregó la recomendación técnica de formato/tamaño.

## 3. Cámara
La experiencia AR ahora está integrada dentro del juego para solicitar el permiso de cámara una sola vez y reutilizarlo en las siguientes provincias dentro de la misma sesión.

## 4. Dato curioso
Se mantiene el bloque posterior a capturar insignia, con botón para reproducir el dato. Mientras no existan audios reales, la versión usa voz del navegador.

## 5. Pasaporte
Se rediseñó en estilo tipo pasaporte, con portada, datos del explorador y sección de sellos/insignias.

## 6. Certificado
Ahora primero se muestra una vista previa web del certificado y luego el usuario decide si descargar el PDF.
